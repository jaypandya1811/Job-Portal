Job Connect

A full-stack Job Portal web application built using the MERN stack.
It allows users to register, upload resumes, browse jobs, and apply for relevant positions users can see applications job wise see resumes of applicants.

🚀 Features

    - User authentication using JWT
    - User registration & login
    - Encrypted password
    - Resume upload using Multer
    - View available jobs
    - Apply for jobs
    - Save jobs for later
    - Error Handling
    - Toastify notifications
    - Secure backend APIs

🛠️ Tech Stack

- Backend

    - Node.js
    - Express.js
    - MongoDB
    - Mongoose
    - JWT Authentication
    - Multer
    - Postman

- Frontend

    - React.js
    - Tailwind CSS
    - React Toastify

▶️ How to Run the Project

- Backend
    - cd backend
    - nodemon (if you have)
    - npm start

- Frontend
    - cd frontend
    - npm run dev
